# FINOMALY · Фронтенд

React, TypeScript, Vite и CSS. По умолчанию приложение запускает локальное демо с синтетическими данными. Официальная проверка Genesis Hackathon запускает Python-среду отдельно.

## Запуск

В папке проекта выполните:

```powershell
npm install
npm run dev
```

Сборка и проверка типов — `npm run build`.

## Демонстрация

[Пользовательский гайд по FINOMALY](USER_GUIDE.md) объясняет назначение экранов, бюджет шагов и метрики. В конце есть короткий сценарий показа.

Для показа в один клик нажмите **«Запустить демо»** на первом экране. Агент начнёт проверку с текущими параметрами. Во время показа доступны пауза и выбор скорости. При обновлении страницы локальный эпизод восстанавливается из ключа генерации и номера шага в хранилище вкладки. В Results кнопка **«Скачать отчёт»** сохраняет автономный HTML для чтения и печати.

1. Выберите один из семи сценариев. Задайте `seed`, границы периода и базовую валюту из восьми вариантов — KZT, USD, EUR, GBP, CHF, CNY, JPY или UZS.
2. В Audit Workspace нажмите ID документа или проводки. Подробности показывают исходную валюту, контрагента и связанные записи.
3. Раскройте шаг в истории, чтобы увидеть параметры запроса, наблюдение, расход бюджета и полученные записи.
4. Запускайте действия вручную или кнопкой «Запустить всё». Скорость управляет интервалом между запросами. «Пауза» останавливает будущие шаги, а уже отправленный запрос может завершиться.
5. На Results откройте узел цепочки доказательств. Метка «Затронута» относится к конкретному выводу.

В локальном демо сценарий и конфигурация изменяют синтетические записи. Метрики и курсы валют демонстрационные. Для повтора задайте ту же конфигурацию и тот же seed.
