# Базовые политики FINOMALY

Измерено на 20 открытых эпизодах. Каждая политика получила одинаковые книги для каждого эпизода. Время от первого запроса политики до завершения эпизода включает обмен JSON для публичных политик. Генерация книг, запись файлов и настройка запуска находятся за пределами замера.

При пустом эталоне и пустой отправке P и R равны 0, а F1 равен 1 по правилам кейса. `random` собирает случайную выборку и отправляет пустой список. `flag_everything` помечает все типы ошибок у первых наблюдаемых строк и расходует лимит выводов. `oracle` получает эталон внутри оценщика и отправляет его без шагов исследования. `reconciliation` выводит расхождения по публичным книгам и оплатам. Разница в возврате при одинаковом F1 показывает цену шагов.
