# FINOMALY

FINOMALY — воспроизводимая среда для разработки и оценки ИИ-аудиторов. Она создаёт виртуальную компанию, даёт агенту инструменты проверки и оценивает его выводы по скрытому эталону. Веб-приложение показывает ход одного прогона и его результат.

## Проверка для жюри

Из корня папки на Python 3.11 выполните:

```bash
python verify.py
```

Команда выполняет тесты, заново генерирует 20 открытых эпизодов, сравнивает выгрузки побайтово и воспроизводит сохранённые действия с проверкой каждого наблюдения и награды. Проверка использует только стандартную библиотеку, без сетевых соединений, браузера, API-ключей и GPU. Тот же режим в контейнере:

```bash
docker build --target verify -t finomaly-verify .
docker run --rm --network none --cpus 2 --memory 4g finomaly-verify
```

Базовый образ Python нужен на этапе сборки. Готовый образ запускается с отключённой сетью.

## Демо в браузере

Запуск из ZIP с готовой сборкой интерфейса. Для первого запуска установите фиксированные веб-зависимости в ваше окружение Python 3.11:

```bash
python -m pip install -r backend/requirements.txt
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

Откройте [FINOMALY на локальном сервере](http://127.0.0.1:8000/). Выберите `Распределение + валютный курс`, затем нажмите «Запустить аудит». В `Audit Workspace` раскройте шаг проверки или откройте документ. В `Results` видны два вывода, доступные доказательства, Precision, Recall, F1 и награда. Кнопка «Скачать отчёт» сохраняет результат прогона.

Для сборки интерфейса из исходников выполните:

```bash
pnpm --dir frontend install --frozen-lockfile
pnpm --dir frontend run build
```

Перезапустите сервер после сборки. Для разработки используйте Node 24 и pnpm 11.25.0. Команда `pnpm --dir frontend run dev` запускает Vite на порту 5173 с прокси `/api` на Python-сервер порта 8000. Пустое значение `VITE_AUDIT_API_URL` в `frontend/.env.local` включает автономный браузерный пример.

Сборка веб-демо в контейнере:

```bash
docker build --target web -t finomaly-web .
docker run --rm -p 127.0.0.1:8000:8000 finomaly-web
```

## Что сдаётся

| Путь | Назначение |
|---|---|
| `backend/app/generator.py` | Синтетическая история компании, бухгалтерские записи, внесение ошибок и экспорт файлов |
| `backend/app/env.py` | `FinAuditEnv.reset(seed, config)` и `step(action)`, бюджет и наблюдения |
| `backend/app/matcher.py` | Взаимно однозначное сопоставление выводов, метрики и награда |
| `backend/app/policies.py` | Случайный исследователь, сверка, массовые обвинения и Oracle для оценщика |
| `backend/app/main.py` | FastAPI, снимки эпизода и HTTP-адаптер для React |
| `backend/tests/` и `verify.py` | Автономные тесты и воспроизведение открытого набора |
| `episodes/` | Десять train- и десять dev-эпизодов, открытый каталог seed и конфигураций |
| `trajectories.jsonl` | Записанные действия, открытые наблюдения и награда train-прогонов сверки |
| `BENCHMARK.md` | Измеренные P, R, F1, возврат, шаги и время четырёх политик |
| `DESIGN.md` | Форматы, правила оценки, границы доступа и ограничения MVP |

Команды для демонстрации без браузера и повторного измерения:

```bash
python demo.py --scenario allocation_fx --policy all
python -m backend.artifacts --output regenerated
```

## API для интерфейса

| Запрос | Что возвращает |
|---|---|
| `GET /api/health` | Готовность сервера |
| `POST /api/episodes` | Новый сеанс, открытые документы и проводки, бюджет 100 шагов |
| `GET /api/episodes/{id}` | Текущий снимок сеанса |
| `GET /api/episodes/{id}/observation` | Последнее наблюдение агента и идентификатор эпизода для `submit` |
| `POST /api/episodes/{id}/step` | Следующее действие и обновлённый снимок |

Пример создания:

```json
{
  "company_name": "Demo Company",
  "scenario": "allocation_fx",
  "error_types": ["partial_allocation", "fx_rate"],
  "seed": 42,
  "base_currency": "KZT",
  "period_start": "2026-10-01",
  "period_end": "2026-10-31"
}
```

Передайте `{"expected_step": 1}` для шага встроенной политики, или `{"expected_step": 1, "action": {"action": "list_records", "table": "ledger", "limit": 20}}` для ручного вызова инструмента. Режим выбирается первым шагом. Повтор одного номера возвращает состояние без повторного расхода шага. Документация запросов доступна по адресу [OpenAPI](http://127.0.0.1:8000/docs).
